📌 Features
Calculate BMI using height and weight
Display BMI value
Display BMI category
Input validation
REST API integration
Store BMI calculation history
React-based user interface
🧮 BMI Formula
BMI = Weight (kg) / Height² (m)

Example:

Weight = 70 kg
Height = 1.75 m
